# 宇宙点状文明体系总体状态二维模拟器

一个在浏览器中运行的二维宇宙文明演化模拟器。宇宙中散布着若干点状文明，它们在两条基础公理下竞争、结盟、增长与灭绝：

1. **生存是文明的第一需要**
2. **文明不断增长和扩张，但宇宙中的物质总量保持不变**

在线体验：<https://dylanblueb.github.io/cosmos_html/>

单文件实现（`index.html`），无任何外部依赖，直接用浏览器打开即可运行。

## 模拟规则概要

- 每个文明拥有资源、规模、等级、效率，以及随机生成的攻击性与合作性。
- 每个周期，文明在自身探测范围（探测范围 × √规模）内感知其他文明，并决定合作、结盟或攻击；资源低于 50 的文明会孤注一掷地掠夺更富有的邻居。
- 文明持续消耗资源，资源充足时增长规模、提升等级；资源耗尽即灭绝。
- 颜色表示资源相对峰值的比例：绿（富足 >60%）、蓝（稳定 30–60%）、橙（贫瘠 10–30%）、红（濒危 <10%）、灰（灭绝）。绿色实线为合作关系，红色虚线为敌对关系。
- 当文明持有的物质低于总量的 30% 时，显示“资源危机”。

### 资源规则

| 规则 | 说明 |
| --- | --- |
| 严格守恒（默认） | 消耗与掠夺损耗流入环境，合作收益与残骸只能从环境中回收，文明与环境的物质之和恒为 10000，对应公理二。 |
| 原版规则 | 与 `axioms.html` 相同：消耗直接消失，合作与击毁奖励凭空产生，物质总量会大幅变化（统计中以 ⚠ 标示）。 |

## 操作

| 操作 | 方式 |
| --- | --- |
| 启动 / 暂停 | 「启动」按钮、空格键、手机底部 ▶ |
| 单步 | 「单步」按钮、→ 键或 S 键、手机底部 ⏭ |
| 重置 | 「重置」按钮、R 键、手机底部 ↺ |
| 查看文明详情 | 点击 / 轻触文明（再次点击或 Esc 取消） |
| 平移 / 缩放 | 拖动画布；滚轮或双指缩放；双击复位视图 |
| 模拟速度 | 「模拟速度」滑块，约为 速度 × 1.2 步/秒（50 ≈ 60 步/秒） |
| 随机种子 | 面板中的种子输入框，或网址参数 `?seed=任意文字`；相同种子 + 相同参数 = 相同演化过程 |
| 手机端 | 宽度小于 768px 时，控制面板收进底部抽屉，点 ⚙ 打开 |

参数说明：

- **初始文明数量**（5–50）：重置后生效。
- **攻击倾向 / 合作倾向 / 增长速率 / 资源利用效率 / 探测范围**：运行中实时生效。

右上角统计面板显示存活/灭绝文明、合作联盟、战争冲突、演化周期、文明持有物质占比、宇宙物质总量，以及存活数、文明物质与冲突数的历史曲线。

## 开发与测试

```bash
node test/harness.js
```

该脚本从 `index.html` 中提取 JS，用桩对象模拟 DOM 与 Canvas，跑通界面主循环，并在多个种子下运行 2000 步，检查无异常、无 NaN、关系对称、严格守恒模式下物质总量不变，同时输出每步耗时。
